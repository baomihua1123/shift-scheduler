# 短期活動排班系統

離線 Windows 桌面軟體，為短期活動的攝影、導播等人員自動排班。

## 取得與執行

**一般使用者（建議）**：下載 GitHub Releases 裡的 `ShiftScheduler-*-win64.zip`，解壓縮後雙擊 `ShiftScheduler.exe`，不需安裝、不需 Python、可離線使用。
打包與發佈步驟見 `docs/GitHub操作說明.md`；給使用者看的說明在 `docs/使用說明.txt`（打包時會放進 zip）。

**資料位置**：預設存放在程式資料夾旁的 `data\shift_scheduler.db`（每台電腦各自獨立；若資料夾不可寫入，改存 `%APPDATA%\ShiftScheduler`）。
更新版本時直接覆蓋程式檔案即可，`data` 不會被動到。每天關閉程式時會自動備份到 `data\backups`（保留 7 天）。

**開發者**：安裝 Python 3.10+ 後 `python -m pip install -r requirements.txt`，再執行 `run.bat`（或 `python main.py`）；
本機打包可雙擊 `build_exe.bat`。

## 使用流程
1. **設定** 頁籤：新增崗位（所有活動共用，可調整順序）。
2. **人員管理** 頁籤：新增人員並複選適用崗位；也可用 Excel 批次匯入（有範本可下載）。
3. **活動專案** 頁籤：新增活動 → 填活動名稱、工作日期與時間、每班時長、（選填）共同休息、所需崗位與每班人數、出席人員 → 「儲存並產生班表」。
4. 「班表」頁：每格可手動換人；右鍵可鎖定格子（重新排班時保留）；下方有班次統計與檢查結果。
5. 確認後可「定稿」（保存快照成為歷史紀錄），或直接「匯出 Excel」。
6. 下次活動：選擇過往活動 → 「複製所選活動的設定」，只需改日期與人員即可。

## 排班規則
- 每個班次的每個崗位名額都必須有人，且人員必須具備該崗位資格；同一人同一班次只在一個崗位。
- 出席者的總班次數盡量接近。
- 盡量做 1 休 1，避免連續上班；共同休息與跨天視為已休息。人力吃緊無法做到時，會在檢查結果中說明。
- **稀缺崗位專任**：預設「自動判斷」——某崗位的合格出席人數 ≤ 每班所需人數 + 1，就由這些人專任，不進入其他崗位輪替，兩組各自計算公平性。若這樣會讓其他崗位人力過緊，系統會自動改為不專任並提示。可在活動設定中針對每個崗位強制專任或強制不專任。
- 班次切分：全活動時長固定；每天（或休息前後各段）最後剩餘時間若小於時長的一半就併入上一班，否則單獨成一班。

## 匯出的 Excel
- 每天一個工作表，名稱為日期（YYYYMMDD）；時間為列、崗位為欄。
- 「人員班次統計」工作表：姓名為欄，各日期與「總計」為列。
- 隱藏的 `_data` 工作表保存活動設定，請勿刪除，匯入時可還原成專案；可見工作表中手動修改過的姓名，匯入時會被採用。

## 測試
`python -m unittest discover -s tests -v`（核心邏輯與無螢幕介面冒煙測試；GitHub Actions 打包前會自動執行）。

## 專案結構
```
main.py                 程式進入點
app/db.py               SQLite 連線與資料表
app/timeslots.py        班次切分
app/engine.py           排班引擎（純 Python）
app/repo.py             資料存取與業務邏輯
app/schedule_view.py    班表檢視資料（快照、匯出共用）
app/excel_io.py         Excel 匯出入
app/backup.py           自動備份
app/ui/                 PySide6 介面
tests/                  單元測試與介面冒煙測試
.github/workflows/      GitHub 自動打包設定
docs/                   使用說明與 GitHub 操作說明
```
